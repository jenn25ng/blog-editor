# 네이버 블로그 AI 에디터

사진·장소·키워드를 입력하면 AI(Claude)가 사진을 분석해, **네이버 검색 상위노출에 맞춰 튜닝된** 한국어 블로그 글을 자동으로 작성해 주는 웹 앱입니다.

## 주요 기능

- 📷 사진 여러 장 업로드 (드래그 앤 드롭, 최대 8장)
- 📍 장소 이름 + 🔑 핵심/연관 키워드 + 추가 정보 입력
- ✍️ 글 스타일 선택 (정보/리뷰 · 여행 감성 · 친근한 구어체)
- ⚡ Claude Vision으로 사진을 실제 분석해 구체적으로 서술
- 🔴 결과 실시간 스트리밍 + 인라인 편집 + 복사
- 📋 네이버 스마트에디터에 **그대로 붙여넣을 수 있는 형식**으로 출력

## 네이버 검색 상위노출을 위한 튜닝 (2026년 로직 기준)

네이버는 **C-Rank**(블로거 신뢰도)와 **D.I.A.+**(글의 경험·유용성 품질)로 순위를 정하고, AI(하이퍼클로바X)가 사람보다 먼저 글을 읽어 *진짜 경험한 글*과 *광고·양산형 글*을 구분합니다. AI로 썼는지 여부보다 **독자에게 실제 답을 주는지, 팩트가 맞는지, 밀도 있게 썼는지**가 노출을 좌우합니다.

이 앱의 프롬프트는 다음을 자동으로 적용합니다.

| 요소 | 적용 내용 |
| --- | --- |
| **진짜 경험의 질감** (D.I.A.+ 핵심) | 1인칭 감각 묘사, 솔직한 단점/팁, 광고성 미사여구 배제 |
| **구체적 수치** | "사람 많았다" → "대기 10~15분"처럼 기준 있는 수치 |
| **팩트 정확성** | 확인 불가한 가격·주소·영업시간은 지어내지 않고 `[ ]` 자리표시자로 남김 |
| **추출 가능한 구조** | 소제목 + "한눈에 요약" 블록으로 AI 브리핑 대응 |
| **키워드 최적화** | 핵심 키워드를 제목 앞쪽 1회·본문 3~5회, 형태소 원형 유지 |
| **제목** | 15~25자, 핵심 키워드 앞배치, 대체 제목 후보 제안 |
| **붙여넣기 형식** | 마크다운 기호 없이, 짧은 문단 + 빈 줄로 모바일 가독성 확보 |
| **사진 배치** | 소제목 사이에 `[사진]` 위치와 캡션 제안 |

### 앱이 대신 못 하는 부분 (직접 챙겨야 할 것)

앱 안의 **"네이버 상위노출 팁"** 패널에도 안내되어 있습니다.

- **한 주제로 꾸준히** 발행 — C-Rank는 특정 분야를 오래 쌓은 블로그를 신뢰합니다.
- **직접 찍은 사진** 사용 — 스톡/펌 이미지는 감점.
- **자리표시자 `[ ]` 채우기** — 발행 전 실제 값으로.
- **채우기 문장 제거** — 밀도가 높아야 체류시간(권장 1분 30초+)이 확보됩니다.
- 저품질로 밀린 글도 **구조·팩트를 고쳐 재저장**하면 1~2주 뒤 재평가됩니다.

> 네이버는 검색 알고리즘을 주기적으로 업데이트합니다. 프롬프트의 원칙(경험·팩트·구조·밀도)은 로직이 바뀌어도 유효한 방향이며, 세부 규칙은 `app/api/generate/route.ts`의 `buildSystemPrompt`에서 조정할 수 있습니다.

## 기술 스택

- [Next.js](https://nextjs.org/) (App Router) + React + TypeScript
- [Anthropic Claude API](https://docs.claude.com/) — 모델: `claude-sonnet-5` (Vision)

## 시작하기

1. 의존성 설치

   ```bash
   npm install
   ```

2. 환경 변수 설정 — `.env.example`을 복사한 뒤 API 키를 입력하세요.

   ```bash
   cp .env.example .env.local
   # .env.local 파일을 열어 ANTHROPIC_API_KEY 값을 채웁니다
   ```

   API 키는 [Anthropic Console](https://console.anthropic.com)에서 발급받을 수 있습니다.

3. 개발 서버 실행

   ```bash
   npm run dev
   ```

   브라우저에서 http://localhost:3000 접속.

## 동작 방식

1. 브라우저에서 선택한 사진을 base64로 인코딩해 `/api/generate`로 전송합니다.
2. 서버 라우트가 Anthropic SDK로 사진(Vision) + 장소/키워드/추가 정보를 Claude에 전달합니다.
3. Claude가 네이버 SEO 규칙에 맞춰 생성한 글이 스트리밍으로 표시되고, 그대로 수정·복사할 수 있습니다.
